# 选型决策：从 rules.md 挑样本与配色

工作流 B 的选型不再凭感觉。按本文件三步走：**给需求打标签 → 打分排序 → 查兼容矩阵**。

## 一、需求标签（五个维度）

从用户需求中提取，缺项按默认值填：

| 维度 | 取值 | 默认 |

| 调性 | 严肃 / 中性 / 活泼 / 文艺 / 清新 | 中性 |
| 密度 | 单句 / 要点（3–5 条）/ 数据 / 图文 | 单句 |
| 比例 | 3:4 / 9:16 / 16:9 / 1:1 / 其他 | 竖版（3:4） |
| 明暗 | 深底 / 浅底 / 中底 / 不限 | 不限 |
| 素材 | 纯文字 / 需实拍图 / 需插画 | 纯文字 |

## 三、打分与输出

**硬筛选**：调性匹配度 + 明暗符合 + 素材可得 → 不合格样本直接剔除。

**打分**（满分 10）：

- 调性完全匹配 +4，接近 +2
- 明暗符合需求 +3，可反转 +1
- 密度匹配 +2，可删减 +1
- 签名元素与内容语义有关联 +1（如 S-09 胶囊对应「一句断言」、S-08 几何图对应「机制解释」）

选出前 3 名，向用户各给一句话理由，**说明为什么是这个样本**，再往下做。用户点名了 S 编号或 C 编号就直接用，跳过打分。

| 中底 | 其余 | 需重设文字色（对比度 ≥4.5:1），谨慎 |

**配色五角色**（每套落地时必须填满，不能只说色值）：

```
--bg      背景        面积 ≥60%          深底或浅底，决定明暗关系
--text    主文字      面积 15~25%        与 bg 对比度 ≥4.5:1
--mid     中间层      面积 5~15%         次要文字、退后的元素、装饰大字
--accent  强调        面积 ≤5%           只给焦点：标签、关键词、细线、小方块
--decor   装饰        面积 ≤3%           细线、纹理、边框
```

## 五、否决记录（选型时主动避开）

负样本比正样本更值钱。每次被用户否掉，记一行，写明「样本/配色、用户原话、问题诊断」。选型时若命中同一组合，先改再提。

| 日期 | 组合 | 用户原话 | 诊断（可迁移的教训） |
|---|---|---|---|
| 2026-11 | 自创·深蓝断线 | 不好看 | 自创色系无依据；装饰线承担叙事却没有信息量 |
| 2026-11 | 自创·纸底克莱因蓝斜块 | 还是一般 | 单块斜切 + 网格 = 模板感，缺签名元素 |
| 2026-11 | 自创·上下分区套印错位 | 不行 | 套版错位是印刷梗，与主题无语义关联 |
| 2026-11 | 自创·克莱因蓝杂志封面 | 再换另一种风格 | 整幅同色 + 只靠字号分层，没有第二块色面 |
| 2026-11 | 自创·竖排中文三列 | 按配色方案…抄一个 | 用户要库里现成范式，不接受自由发挥 |
| 2026-11 | S-01 + C-04 初版 | 大小字都堆在一起了 | 行距 1.14 太紧、副题紧贴标题；大字与副题垂直间距需 ≥画布高 5% |
| 2026-11 | S-08 + C-01 图示 v1 | 图示与文字重复 | 图示把正文已写的例子（闹钟/下床）拆成两个框复述一遍；图示应表达机制或隐喻，不复述正文已述内容 |
| 2026-11 | S-08 + C-01 图示 v4 | 过得去 | 通栏深色块 + 一条横线 + 三个虚线空框，语义成立但图形信息量低，属「安全但不惊艳」——及格线，不是上限 |

**规律**：用户否决集中在两类——(1) 自创而非从库选型；(2) 版面缺少「第二块色面」或「签名元素」，只剩底色 + 字。**第三类（图示向）**：图示复述正文例子 = 信息浪费；图示只画「一条线 + 几个空框」= 及格但不出彩。图示要承载正文没写出来的那层关系（时间、因果、数量、消失的决策点），并且至少有一个可辨认的实体形状，不能只有抽象方块。

**图示合格线（三条同时满足才算过关）**：① 不复述正文已有的具体例子；② 表达正文未明说的一层关系；③ 图形本身有辨识度（有形状、有方向、有对比），不是纯几何色块排列。
