# 投喂图分析模板

每次用户投喂设计图，按本模板逐张分析，并沉淀为 `rules.md` 的一个条目。多张图属于同一「设计方向」时可合并为一个样本（内部标注变体）。

**两种模式**：
- **完整分析**（默认）：按下方「样本条目字段」全部分析，沉淀为 S-序号样本。
- **仅配色分析**：用户标注「只需配色」「只分析配色」，或图片明显是色卡/配色灵感图（纯色块、色彩板）时使用，按「仅配色模式」字段分析，沉淀为 C-序号配色方案。

**编号规则**：取 `rules.md` 索引表末尾的占位行编号（当前为 `S-25` / `C-10`），把正式条目插在占位行之前，并在末尾补一行新的占位行；同时按 `SKILL.md` 工作流 A 更新 `selection.md` 的标签表与兼容矩阵。禁止复用或跳号。

**单位规则**：条目里「字号为画布短边的 N%」一律按 `baseline.md` 的「单位约定」换算为 `cqw`（竖版）/ `cqh`（横版），不要写成 CSS 原生 `font-size: N%`。

## 仅配色模式字段

### 1. 基础
- **配色方案编号**：C-<序号>（沿用 rules.md 索引表）
- **配色氛围关键词**：2~3 个词（如：高饱和撞色、莫兰迪低饱和、暗夜高级感、清新马卡龙）
- **适用场景**：什么调性的页面可用这套色（演讲金句、品牌宣传、数据页、趣味教学…）

### 2. 色板（必须给可落地色值）
- 主色（背景/大面积）：hex + 面积占比
- 辅色：hex
- 强调色（焦点/数字/标题）：hex
- 中性色（正文/标注）：hex
- 明暗关系：深底浅字 / 浅底深字 / 中间调
- 配色公式：一句话说明"什么色配什么用途"

### 3. 可复用实现要点
- `:root{}` 色板变量片段（CSS 可直接抄）。
- 五角色（bg / text / mid / accent / decor）落地值，供 `selection.md` 第四节登记。

## 样本条目字段（完整分析）

### 1. 基础
- **样本编号**：S-<序号>（沿用 rules.md 索引表）
- **风格关键词**：3~5 个词（如：克制商务、热血大字、清新杂志、暗色科技、复古报纸）
- **适用场景**：什么主题/调性的需求适合（演讲金句、产品发布、知识分享、活动宣传…）
- **明暗关系标签**：深底 / 浅底 / 中底（必须与 `selection.md` 标签表及兼容矩阵一致）

### 2. 配色（必须给可落地色值）
- 主色（背景/大面积）：hex + 面积占比
- 辅色：hex
- 强调色（焦点/数字/标题）：hex
- 中性色（正文/标注）：hex
- 明暗关系：深底浅字 / 浅底深字 / 中间调
- 配色公式：一句话说明"什么色配什么用途"

### 3. 构图
- 布局类型：居中大字 / 左对齐分栏 / 上下分割 / 几何分割 / 网格 / 出血图…
- 焦点位置：页面哪一块最先被看到
- 留白：大致比例、集中在哪里
- 栅格：几列、对齐方式、元素间距规律
- 阅读层级：从大到小的阅读顺序

### 4. 字体
- 标题：风格（衬线/无衬线/手写/描边）、字重、字距、是否大写/竖排
- 层级：几级、各级字号相对画布短边的比例
- 对齐：居中/左对齐/两端对齐

### 5. 装饰与质感
- 图形元素：几何色块、线条、圆点、网格、水印大字…
- 纹理/质感：渐变、噪点、纸纹、玻璃、颗粒…
- 边框/编号：边框样式、编号形式
- **签名手法**：最不能丢的那个视觉动作（色块压字、白底块、出血装饰…），必须写清楚形态与实现，不能只写风格词

### 6. 内容密度与比例
- 适合的信息量：单金句 / 少量要点 / 中等图文 / 密集数据
- 适合的宽高比：横版 / 竖版 / 方形，及原图比例
- 该比例下的布局要点

### 7. 可复用实现要点（最重要）
- 直接可抄的 CSS：色板变量（`:root{}`）、字号与间距数值、关键布局代码片段，3~8 条。
- 原图存 `references/samples/` 并登记 README；条目里写明对应图片文件名，便于工作流 B 对照。
