# 规则库（增量沉淀）

本文件是本技能的核心资产：每投喂一批设计图，按 `analysis-template.md` 追加条目并登记索引。**完整分析沉淀为样本条目（S-序号），仅配色分析沉淀为配色方案条目（C-序号）**。生成页面时按 `selection.md` 的五维打分从本库选型（配色方案按「C × S 兼容矩阵」叠加到样本布局上）；库为空或未命中时用 `baseline.md`。

## 单位约定（读下方 CSS 前必看）

各条目「可复用实现要点」里的 `font-size: 9%`、`font-size: 2.2%` 等，是「**画布短边的 9% / 2.2%**」的简写，**不是 CSS 原生百分比**——原生 `%` 相对父元素字号，照抄会让文字几乎不可见。落地时统一换算：竖版 `N%` → `N cqw`，横版 `N%` → `N cqh`；`.stage` 需声明 `container-type:inline-size`。定位用的 `top / left / width: N%` 是原生百分比，保持不变。完整换算与替代写法见 `baseline.md` 的「单位约定」。

## 编号约定

索引表末尾的 `S-25` / `C-10` 是**占位行**：新增条目时取该编号、把正式条目插在占位行之前，并在末尾补一行新的占位行。新增样本还要同步登记 `selection.md` 的标签表与兼容矩阵。

## 样本条目

### S-01 深绿底大字排印 · 教学分享海报

来源：用户投喂图 1（2480×3307，约 3:4 竖版）。品牌水印/落款信息已忽略，只取设计本体。

**风格关键词**：深绿商务、大字排印、克制简约、留白呼吸、教学分享

**适用场景**：设计/知识教学类分享页、竖版观点页（金句+主题）、品牌宣传海报；演讲场景中适合做「章节页/主题页」或竖屏分享卡。

**配色**（色值取自 extract_palette.py，装饰色为近似）：

| 角色 | 色值 | 面积/用途 |
|---|---|---|
| 主色（背景） | `#197662` 深绿 | 约 74%，整页底色 |
| 辅色（装饰） | `#769373` `#819574` `#9ab18d` 灰绿系 | 约 20%，右侧艺术字母、次要元素 |
| 强调色 | `#cb5a48` 红棕 | 小面积，标签/重点词（如「直接抄」） |
| 中性色（文字） | `#dece9d` 米白（近似） | 大标题、副题、正文 |

- 明暗关系：**深底浅字**（深绿底 + 米白字），局部红棕小面积点缀。
- 配色公式：深色大面积打底 → 米白做主文字 → 同色系浅色做装饰层级 → 红棕小面积强调重点词。全页只用 1 个强调色，且面积占比极小。

**构图**：
- 布局类型：**左对齐大字排印 + 右侧出血艺术字母装饰**，底部品牌信息横条收尾。
- 焦点位置：左上大标题区（「5种 / 海报构图 / 公式」三行大字，最先被看到）。
- 留白：标题区在上 2/5 之后有大面积留白，右侧由装饰字母填充边缘，整体「上紧下松」。
- 栅格：标题严格左对齐成一列；装饰贴右缘；底部信息单行横排。
- 阅读层级：小标签（红色「直接抄」）→ 超大标题（白/米白）→ 副题（小字一行）→ 底部品牌信息。

**字体**：
- 标题：无衬线黑体类，超大字号、粗字重、字距偏宽；大标题字号约为画布短边 **14%~17%**。
- 层级：3 级——超大标题（短边 14%~17%）、副题（短边 2.5%~3%）、底部标注（≤2%）。
- 对齐：全部左对齐。

**装饰与质感**：
- 右侧浅灰绿大号英文字母竖排（艺术字装饰），半透明/低对比，不抢标题焦点。
- 纯色扁平底，无明显纹理、无渐变。
- 底部品牌条：名称 + 服务类型 + 联系方式单行排列（本次为「名称 / 服务词 / DESIGN / 抖音号」）。

**内容密度与比例**：
- 信息量：单主题海报（标题即主题），几乎无正文要点，靠大字与留白撑版。
- 适合比例：**竖版 3:4 / 9:16**；改为横版时把「左标题 + 右装饰」转成「左标题 + 右装饰」左右分栏即可。
- 竖版布局要点：标题区占上 2/5、装饰贴右缘出血、底部信息条收尾、中下部保持大面积留白。

**可复用实现要点（CSS）**：
```css
:root{
  --bg:#197662;            /* 主色背景 */
  --deco:#769373;          /* 装饰灰绿 */
  --accent:#cb5a48;        /* 强调红棕 */
  --ink:#dece9d;           /* 主文字米白 */
}
/* 画布（以 3:4 为例，任意比例改 --w/--h） */
.stage{ --w:3; --h:4;
  width:min(100vw, calc(100vh * var(--w) / var(--h)));
  aspect-ratio:var(--w)/var(--h);
  background:var(--bg); position:relative; overflow:hidden;
}
/* 大字标题：左对齐、短边 14%~17%、粗字重、宽字距 */
.title{ font-weight:800; letter-spacing:.08em; line-height:1.15;
  font-size:calc(min(100vw, 100vh * var(--w)/var(--h)) * 0.15);
}
/* 右侧装饰字母：绝对定位贴右缘、半透明灰绿、竖排出血 */
.deco{ position:absolute; right:-4%; top:2%; bottom:2%;
  color:var(--deco); opacity:.55; writing-mode:vertical-rl;
  font-weight:900; letter-spacing:.2em; user-select:none;
}
/* 强调词标签：小面积红棕，压在标题上方 */
.tag{ color:var(--accent); font-weight:700; font-size:2.2%; }
/* 底部品牌条：单行横排、低对比小字 */
.foot{ position:absolute; left:8%; right:8%; bottom:6%;
  display:flex; gap:1.5em; align-items:baseline;
  color:var(--deco); font-size:1.8%; letter-spacing:.06em; }
```
- 注意：大标题与副题、底部条的间距用画布相对单位（% 或 vmin 换算），保证任意比例下成画。

### S-02 黑底荧光色块 · 高对比教学海报

来源：用户投喂图 2（1152×2376，9:16 视频截图，已忽略状态栏与播放条）。品牌名「樱和必/动静视觉」等落款忽略。

**风格关键词**：黑底荧光、高对比、色块版式、抓眼球

**适用场景**：干货教学、直播/短视频封面、需要第一眼抓眼的竖版分享页；演讲中适合做「开场冲击页」。

**配色**（色值取自脚本）：

| 角色 | 色值 | 面积/用途 |
|---|---|---|
| 主色（包边背景） | `#050503` 黑 | 约 62%，上下黑底 |
| 主色（内容区） | `#bbf20b` 荧光黄绿 | 约 30%，中间色块 |
| 文字 | 深黑（黑字压在亮块上） | 大标题 |
| 次级文字 | 白/灰（黑底上小字） | 顶部经验值、英文副题 |

- 明暗关系：**上下黑 + 中间荧光色块**，亮块上压深黑大字，高对比。
- 配色公式：黑色大面积包边 → 荧光黄绿做内容色块 → 深黑粗字压在亮块上。全页只用一个高饱和撞色，与黑底形成强烈反差。

**构图**：
- 布局类型：**上下分割三段式**（黑-荧光块-黑），内容集中在中间色块，色块外只放少量辅助信息。
- 焦点：中间色块内的大标题（「可以直接"抄"的海报构图」）。
- 层级：色块顶部小字（16年实战经验）→ 色块内大标题 → 色块内英文副题 + 底部黑底中文副题（设计科学-让你成为设计高手）。
- 细节：色块右侧边缘有竖排英文小字（DESIGN SCIENCE），作质感点缀。

**字体**：大标题无衬线粗黑、字重 800+，横跨色块宽度；辅助英文小字作细节层。

**装饰与质感**：无渐变无纹理，纯靠「黑 vs 荧光」色块对比制造冲击；英文小字竖排/横排作细节。

**内容密度与比例**：单主题干货页，信息量小；原生 9:16，黑边可作安全区。

**可复用实现要点（CSS）**：
```css
:root{ --black:#050503; --neon:#bbf20b; }
.stage{ --w:9; --h:16;
  width:min(100vw, calc(100vh * var(--w)/var(--h)));
  aspect-ratio:9/16; background:var(--black);
  display:grid; grid-template-rows:1fr auto 1fr; position:relative;
}
.block{ background:var(--neon); color:#050503; padding:8% 10%;
  font-weight:900; letter-spacing:.06em; }
.block .title{ font-size:9%; line-height:1.2; }
.frame-note{ color:#bbb; font-size:2%; }  /* 黑底上的小字 */
```
- 三段式用 grid 三行；色块内标题字号按画布宽度的 9%~10%；黑底文字低对比小字。

### S-03 亮黄底黑白大字 · 数字强化分享海报

来源：用户投喂图 3（1152×2376，9:16 视频截图，已忽略状态栏与播放条）。品牌「有风视觉/WINDY VISION」忽略。

**风格关键词**：亮黄、黑白、大字排印、数字放大、极宽字距英文

**适用场景**：资源合集分享（「第02期」「100张」）、收藏型干货、高饱和抓眼的素材分享页。

**配色**（色值取自脚本）：

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色（背景） | `#fed34a` 亮黄 | 约 52%，整页底 |
| 文字 | `#100f0d` 黑 / `#4c4735` 深棕黑 | 标题、正文 |
| 点缀 | `#fcf9ec` 米白 | 小标签/白底黑字区块 |

- 明暗关系：**亮底深字**（亮黄底 + 黑字），局部黑白反转（黑底白字小标签）。
- 配色公式：亮黄做底 → 黑字做主信息 → 米白小面积做标签反转。高饱和底 + 黑白字，不加第三色。

**构图**：
