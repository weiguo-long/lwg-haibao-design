# 交付前验收清单（12 项）

写完 HTML 不等于做完。按下表逐项过，任何一项不通过就改完再交付。

**先做两项核算**：本环境 `scripts/shot.py` 可能不存在，用两种方式代替——

1. **换算核算**（必做）：把 cqw 换算成像素手算一遍。3:4 画布 900×1200 时 `1cqw = 9px`；手机 390px 视口、画布 `min(94vw,…)` ≈ 366px 宽时 `1cqw ≈ 3.66px`。位置用百分比换算：`top:17%` → 204px。
2. **渲染截图**（能用就用）：`open_url_in_browser` 打开本地 html → 截图 → 只看三件致命事：文字出界、元素压字、色面对比是否成立。截图工具不可用时，在交付说明里如实写「未做渲染自检」。

## 清单

| # | 检查项 | 标准 | 不通过怎么改 |
|---|---|---|---|
| 1 | 画布比例 | `aspect-ratio` 与用户要求一致；`width:min(94vw,Npx)`，不写死高度 | 改 `aspect-ratio`，元素全部用 % / cqw 定位 |
| 2 | 标题字号 | 短边 **11%~17%**（3:4 的 900 宽 → 99~153px）；超过 18% 会挤掉一切 | 降字号，靠行距和留白撑气魄 |
| 3 | 字号阶梯 | 至少 3 级，相邻级比值 ≥ **1.8**（如 104 / 26 / 14） | 中间层加一级，或把标注缩到 2/3 |
| 4 | 行距 | 大标题 1.10~1.30；正文/副题 ≥1.6；小于 1.1 必糊 | 行距 +0.1、字号 −1%，两者同时动 |
| 5 | 大小字净距 | 大字组与小字组垂直净距 ≥ **画布高 5%**（3:4 → 60px） | 小字组整体下移或上移，不要靠缩字号腾位置 |
| 6 | 对比度 | 文字与背景 ≥ **4.5:1**；深底浅字、浅底深字 | 换 text 色，或给文字加一层同色系深/浅底 |
| 7 | 安全边距 | 左右 ≥ 短边 6%、上下 ≥ 4%；出血装饰**只贴一条边** | 收边距；出血元素别四面满铺 |
| 8 | 单一焦点 | 全页只有 1 组 900 字重大字；其余降字重/降透明度 | 副题降 500、装饰降 42% 透明度 |
| 9 | 颜色数量 | 主 1 + 辅 ≤2 + 强调 1；强调面积 ≤5% | 删多余色；强调只留标签/细线/小方块 |
| 10 | 元素不重叠 | 绝对定位元素的外接矩形互不相交（重点：竖排装饰 vs 标题右缘、胶囊 vs 左下文字） | 算一遍：`left% + width% ≤ 右邻 left%` |
| 11 | 行长 | 单行 ≤ 20 个中文字；文本块宽 ≤ 65% 画布 | 手动 `<br>` 断行，或缩窄 max-width |
| 12 | 手机可读 | 390px 视口下正文 ≥14px 等效 → 字号 **≥3.6cqw**；低于 2cqw 的只许做装饰，不许承载必要信息 | 正文加字号，或用「大字压小字」的双层结构 |

## 两条硬规矩

- **宁可少一个元素，不要多一个抢焦点的元素**。每加一层，先问它是否承担信息角色。
- **改写前先 `cp` 到 `_backup/`**；交付时 `artifacts[].name` 写文件名，不另起标题。

- 用户若提了具体不适（如「字堆在一起」），说明改了哪几个参数，而不是笼统说「优化了」
