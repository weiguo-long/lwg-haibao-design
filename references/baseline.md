# 通用基线：海报风格演讲页设计规则

规则库（rules.md）为空或不匹配时使用本基线。所有规则以"可直接落地为 CSS"为准。

## 配色

- 结构：主色 + 辅色 + 强调色 + 中性色（背景/文字），控制在同一色系体系内。
- 数量：全页主色 1 个、辅色 ≤2、强调色 1 个、中性色 2~3 个。禁止彩虹色板。
- 可读性：正文与背景对比度 ≥ 4.5:1。深底配浅字、浅底配深字，不要大面积低对比配色。
- 强调色只用于：主标题、关键数据、焦点元素、CTA，不铺满全页。

## 构图（版面）

常见布局模式：

| 模式 | 结构 | 适合内容 |
|---|---|---|
| 居中大字型 | 焦点在中上，标题居中 | 金句页、观点页 |
| 左对齐分栏型 | 标题左、内容右（或反之） | 多要点、图文混排 |
| 上下分割型 | 上图下文 / 上文下图，色块或留白分割 | 数据页、章节页 |
| 几何分割型 | 斜切、色块、圆角块分割版面 | 强调视觉冲击的活动/产品页 |
| 网格型 | 等宽卡片栅格 | 多要点、议程、案例集 |

- 留白：四周留白 ≥ 画布短边 8%；留白用于分组与呼吸，不得用留白撑版面。
- 层级：一个页面只有一个视觉焦点；次要信息缩小、降对比，不得加亮抢焦点。
- 平衡：各区块视觉均衡分布，禁止单侧堆积、上重下空或下重上空。

## 字体层级（4 级，以画布短边为基准）

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 大标题 | 14%~18% | 700+ | 页面主观点，一行内闭合 |
| 副标题/核心观点 | 6%~9% | 500~700 | 支撑句、分论点 |
| 正文 | 3.5%~5% | 400 | 说明文字，行高 1.5+ |
| 标注/来源 | ≤2.5% | 400 | 脚注、页码、来源，低对比中性色 |

- 中文字体优先系统字体栈（思源黑体/苹方/微软雅黑等）；英文可用衬线或几何无衬线制造风格。字体数量 ≤3。
- 层级靠字号、字重、行长与语义断行建立，不靠堆字体数量。

## 装饰与质感

- 装饰服务层级与焦点：分割线、几何色块、编号、内联 SVG 图标均可；禁止无信息价值的堆砌。
- 可用：细网格背景、大字水印、圆角色块、边框编号、点线纹理。
- 慎用：大面积渐变、玻璃拟态、发光边框、emoji。

## 比例适配规范（任意比例）

- **画布**：固定比例容器 + 自适应。推荐结构：
  - 容器用 CSS 变量 `--w` / `--h`（如 16 与 9），`aspect-ratio: var(--w) / var(--h)`；
  - 容器尺寸 `width: min(100vw, calc(100vh * var(--w) / var(--h)))`，页面级 `<section>` 按比例闭合成一屏；
  - 内部元素用百分比/相对单位定位，保证任意比例下整页成画。
- **字号换算**：以上表"画布短边百分比"为基准等比缩放；竖版（9:16 等）标题可略放大、正文行宽收紧；横版（16:9 等）正文可稍放大。
- **断点**：任意比例下都保证单屏成画；窄屏（<768px）字号下限 14px、输入控件 16px。
- **装饰层**：背景装饰放独立绝对定位层（`aria-hidden="true"`），不要给正文容器加 `overflow:hidden` 裁装饰。

## 演讲页内容惯例

- 金句页：一句主观点 + 一个支撑句/署名，居中大字型。
- 观点页：主标题 + 3~5 个要点（图标/编号 + 一句话），左对齐或网格。
- 数据页：1~3 个关键数字放大 + 简短说明，数字用强调色。
- 议程页：时间轴或编号列表（圆点/轴像素级对齐）。
- 章节过渡页：大编号 + 章节名，极简。

## 禁例

- 堆 emoji、无意义渐变、僵尸按钮、超大留白撑页、字体超过 3 种、正文低于 14px、每屏多个视觉焦点。
